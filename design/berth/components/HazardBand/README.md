# HazardBand

Ink-and-quay diagonal stripes taken from the markings on a quay edge. They mark trunk, the line only the queue crosses.

- Markup: `<div class="bt-hazard" role="presentation"></div>`, followed by a text label that says what the line is.
- Use it in two places only: above the trunk lane on the Landed view, and on the change the queue is currently landing.
- Never use it for decoration, warnings or empty states. If it appears everywhere, it means nothing.
