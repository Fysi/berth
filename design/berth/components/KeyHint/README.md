# KeyHint

A key cap for keyboard shortcuts, drawn in the colour of the text around it.

- Markup: `<span class="bt-kbd">V</span>`. You provide the key. Use the real key name (`Esc`, `↵`, `?`).
- Berth is keyboard-first: every primary action has a shortcut, and its button shows it.
- Put a hint inside a button or next to the action it triggers. Don't put hints in body text.
