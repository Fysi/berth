# Logos

The mark is a change docked in its berth: a quay-yellow block sitting in an ink slot, with 3px of clearance on every side. The wordmark is "berth" in lower case, set in Archivo Expanded 800 and outlined.

- `berth-lockup-on-light.svg`: mark and wordmark, ink `#121413`. Use on `concrete` and `slab` in the light theme.
- `berth-lockup-on-dark.svg`: mark and wordmark, ink `#edeee9`. Use on `concrete` and `slab` in the dark theme.
- `berth-mark-on-light.svg` and `berth-mark-on-dark.svg`: the mark alone, in the same two inks. Use where the name is already on screen, and at 24px or smaller.
- `berth-app-icon.svg`: the dark mark on an ink square. Use for favicons, app icons and avatars.

Each file has one fixed ink. The block is always `quay` yellow `#ffc21a`. Pick the file that matches the theme, because an `<img>` can't inherit colour.

- Minimum size: mark 16px, lockup 20px tall.
- Clear space: the slot's width (12px at 48px) on every side.
- Never rotate the mark, recolour the block, put the logo on a quay or buoy fill, or set the wordmark in live text.
